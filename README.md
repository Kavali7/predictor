# Numerology Web (Vite + React + TS)

## Prérequis
- Node.js 18+

## Installation & Démarrage
```bash
npm i
npm run dev
```
Ouvre l'URL affichée (ex: http://localhost:5173).

## Édition de contenu
- Individuel: `src/app-content/content/individual/1.json..9.json`
- Couple: `src/app-content/content/couple/1.json..9.json`

## Code
- Calculs: `src/app-content/src/numerology.ts`
- Loader: `src/app-content/src/contentLoader.ts`
- Page: `src/App.tsx`
